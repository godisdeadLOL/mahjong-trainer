# 🀄 mahjong-trainer

Интерактивный тренажёр для повышения эффективности игры в риичи-маджонг.

---

## 🌍 Попробовать

🔗 [Открыть сайт](https://godisdeadlol.github.io/mahjong-trainer/)

## ✨ Особенности

- 📊 Оценка эффективности ходов
- ↩️ Отмена последнего хода
- 🌙 Темная тема с альтернативными тайлами

## ⚙️ Как это работает

При каждом ходе рассчитывается укеире — количество потенциальных выигрышных тайлов после сброса. Программа анализирует ваш выбор и оценивает эффективность хода.
